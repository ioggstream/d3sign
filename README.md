# Design & D3FEND

Design & D3FEND is a single page application
that helps designing secure IT architectural diagrams
reusing knowledge graphs like Mitre D3FEND
and the Data Privacy Vocabulary.

Write your design document as a markdown file,
and include Mermaid JS flowchart diagrams.

Then annotate each node with its D3FEND type,
like it is done in the examples.

The application will show an aggregate diagram
where every node is connected with the others.

Double clicking on a node shows its properties
and its neighbours.

You can filter out by node types (e.g., Actors,
Artifacts, ...);
or by link type (e.g., data flow, control flow).

Moreover you can fold/unfold containing nodes.

Editing and navigation are based on keyboard
shortcuts.

You can save your ongoing work into the browser cache,
so you have a basic protection in case of web page reload.
